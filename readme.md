# OpenSourceMentor AI — ML

This repository contains the **Machine Learning part** of the OpenSourceMentor AI project.

## 🚀 Project

OpenSourceMentor AI helps students understand their GitHub skills and find suitable open-source contribution opportunities.

### Current Focus

At the current stage, the system analyzes GitHub repositories and extracts useful information that can later be used for skill detection and recommendations.

## ✅ Completed

* GitHub repository data extraction
* Programming language extraction
* GitHub topic extraction
* README extraction

## 🔄 In Progress

* `package.json` dependency extraction
* Python dependency extraction
* `requirements.txt` analysis
* `pyproject.toml` analysis

## 🧠 Planned ML Work

* Technology and skill detection
* Student skill profile
* Issue requirement analysis
* Skill-gap analysis
* Open-source issue matching
* Personalized recommendations

## 🔗 Backend Integration

The ML service will communicate with the Node.js backend using APIs.

```text
GitHub
   ↓
Backend
   ↓
Repository Data
   ↓
ML Service
   ↓
Skill Analysis
   ↓
Recommendations
```
